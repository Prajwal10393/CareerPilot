# CareerPilot

CareerPilot is a full-stack placement and career management web application designed to help students manage their placement journey while providing administrators with tools to manage students, companies, placement drives, results, and analytics.

## 🚀 Features

### Student Portal
- Student Registration and Login
- JWT Authentication
- Student Profile Management
- Profile Completion Tracking
- Skills Management
- Job Application Tracking
- Placement Drive Discovery
- Eligibility Checking
- AI Resume / ATS Analyzer
- Company-Specific Resume Matching
- Interview Management
- Offer Management
- Placement Results
- Placement Calendar and Events
- Notifications
- Placement Analytics
- Practice Questions
- Interview Question Generator

### Admin Portal
- Secure Admin Login
- Admin Dashboard
- Student Management
- Company Management
- Placement Drive Management
- Placement Result Management
- Reports
- Placement Analytics

## 📁 Project Structure

CareerPilot contains two main applications:

- `careerpilot-frontend` — React frontend
- `careerpilot-backend` — Node.js and Express backend

## 🔐 Security

Sensitive information such as environment variables and database configuration is excluded from the repository using `.gitignore`.

## 🎯 Project Objective

The objective of CareerPilot is to provide students with a centralized platform for managing placement activities, improving interview preparation, analyzing resumes, tracking applications, and monitoring placement progress.

The Admin Portal helps placement administrators manage students, companies, placement drives, placement results, reports, and analytics from a centralized dashboard.
